# Sound Example

Plays the ColecoVision's sound chip from the cart: notes on one voice, a drum on the noise voice.

## Controls

- Keypad 1 to 8: a note of the scale, while held
- Stick up, down: the octave
- Left fire: a drum
- RESET: back to the menu
