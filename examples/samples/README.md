# Samples Example

Notes and a drum played as samples, about 6,000 a second, through the
console's sound chip used as a DAC. The command lists run back to back,
so each list's length is the sample clock. The wave shows on the TV.

## Controls

- Keypad 1-8: a note, C to C
- Fire: a drum
- RESET: back to the menu
